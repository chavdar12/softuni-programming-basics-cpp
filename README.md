## Run

Needs CMake and a C++17 compiler. Every lecture folder is a CMake project; each exercise has `tests/*.in` / `*.out`
pairs that CTest feeds through the program.

```bash
cmake -S 005-Conditional-Statements-Advanced -B build/005-Conditional-Statements-Advanced
cmake --build build/005-Conditional-Statements-Advanced
ctest --test-dir build/005-Conditional-Statements-Advanced --output-on-failure
```
